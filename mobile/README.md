# Android Java Native SSO Demo

## Apps

- `super-app`: performs the first eSignet authorization-code login and stores `id_token`, `access_token`, and `device_secret` in an encrypted Android Keystore-backed store.
- `child-app`: requests the Native SSO artifacts from the Super App through a signature-level Android permission and performs the token exchange.

## Same-certificate requirement

Build both APKs with the same Android signing key. For a local debug build, Android Studio/Gradle normally uses the same default debug keystore for both modules. For a submission build, configure an explicit shared signing configuration.

## Client registration

Register two OIDC clients:

- `super-app` → redirect URI `nativesso-super://oauth/callback`
- `child-app` → no browser redirect required for Native SSO

Both clients should use `private_key_jwt` and the public JWK generated by their Android Keystore key. The `kid` is the client ID in this demo.

The Super App client must include:

```json
{
  "allowed_authorization_scopes": ["device_sso"]
}
```

## Configuration

Edit `SsoConfig.java` in both apps:

```java
public static final String ISSUER = "http://10.0.2.2:8088";
```

Use `10.0.2.2` for an Android emulator talking to a host service. Use the host's LAN IP for a physical device.

## Demo sequence

1. Install both APKs.
2. Open Super App.
3. Tap **Sign in with eSignet**.
4. Complete the normal eSignet login and consent.
5. Return to Super App.
6. Open Child App.
7. Tap **Sign In with Native SSO**.
8. Child App invokes the signature-protected Super App bridge.
9. Super App returns the ID Token, device secret, and a fresh DPoP proof bound to the original key.
10. Child App calls `/oauth2/token` with `grant_type=token-exchange` and `actor_token_type=urn:openid:params:token-type:device-secret`.
11. Child App receives an access token without another browser authentication.

## Public JWK

Both apps log their generated public JWK at startup under the tag `NativeSSO`. Register that JWK with eSignet using the matching `kid`.

## Project selection and build
Open the `mobile` folder as the single canonical Android Studio project. Do not open the old `mobile/android/SuperApp` or `mobile/android/ChildApp2` starter projects. Use the root wrapper (`gradlew.bat assembleDebug`) with JDK 17 and Android SDK 35.

For local emulator development, the app manifests allow cleartext HTTP because `10.0.2.2` is a host-emulator bridge. This is demo-only; use HTTPS and disable cleartext for any release/production build.
